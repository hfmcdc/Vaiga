# Vaiga Sweets & Snacks — Website

A modern, mobile-first website for Vaiga Sweets & Snacks, a Kerala sweets
and snacks brand serving customers since 2020.

## 1. Project overview

This is a marketing + light e-commerce site: it presents the brand, product
categories, and featured products, and routes every order to WhatsApp
(with a call/email fallback) rather than a full checkout system. All
content — products, prices, contact details, and social links — lives in
plain data files so it can be updated without touching component code.

## 2. Tech stack

- **Next.js 15** (App Router) + **React 19** + **TypeScript**
- **Tailwind CSS v4**
- **lucide-react** for icons
- `next/image` for optimized images
- No database, no CMS, no backend — content lives in `src/data/*`

## 4. Environment variables

Copy `.env.example` to `.env.local` and fill in real values:

| Variable | Purpose |
|---|---|
| `NEXT_PUBLIC_WHATSAPP_NUMBER` | Digits only, with country code (e.g. `919000000000`). Used to build every "Order Now" / WhatsApp link. |
| `NEXT_PUBLIC_PHONE_NUMBER` | Phone number shown in the footer and contact page. |
| `NEXT_PUBLIC_EMAIL` | Public contact email address. |
| `NEXT_PUBLIC_INSTAGRAM_URL` | Instagram profile link. |
| `NEXT_PUBLIC_FACEBOOK_URL` | Facebook profile link. |

If a variable isn't set, the site falls back to a placeholder value defined
in `src/data/site.ts` — nothing will crash, but update these before
launch.

## 5. How to add or edit products

Edit `src/data/products.ts`. Each product is a plain object:

```ts
{
  slug: "banana-chips",        // unique, used as a React key
  name: "Banana Chips",
  description: "...",
  image: "/images/products/banana-chips.svg",
  category: "banana-specials", // must match a slug in src/data/categories.ts
  price: "Contact us",         // keep as a friendly placeholder unless you want real prices shown
  available: true,             // set false to show "Currently unavailable"
  featured: true,              // true = shows on the homepage featured grid
}
```

Add a new object to the array to add a product — no other file needs to
change. The products page and its category filter read from this same
list automatically.

## 6. How to replace images

All images are centralized under `/public/images/...` and referenced by
path in the data files (`src/data/products.ts`, `src/data/categories.ts`,
`src/data/gallery.ts`) or directly in a component (hero, about page).

The project currently ships with **placeholder artwork** (warm, brand-
colored SVGs, generated by `scripts/gen-placeholders.mjs`) standing in for
real food photography. To replace them:

1. Drop your real photo into the matching folder, e.g.
   `/public/images/products/banana-chips.jpg`.
2. Update the `image` path for that item in the relevant data file.
3. Recommended sizes: product/category images ~1000×1000px (square),
   hero image ~1600×1400px, gallery images any aspect ratio (the gallery
   uses a masonry layout).
4. Keep file sizes reasonable (a few hundred KB) — `next/image` will
   still optimize and lazy-load them, but smaller originals load faster.

## 7. How to update the WhatsApp number

Set `NEXT_PUBLIC_WHATSAPP_NUMBER` in `.env.local` (and in Vercel for
production). Every WhatsApp button on the site is built from
`src/lib/whatsapp.ts`, which reads from `src/data/site.ts`, which reads
from that one environment variable — there is nothing else to update.

## 8. How to update social links

Set `NEXT_PUBLIC_INSTAGRAM_URL` and `NEXT_PUBLIC_FACEBOOK_URL` in your
environment, or edit the fallback values directly in
`src/data/site.ts` under `social`.

## 9. Connecting the contact form

The contact form (`src/components/contact/ContactForm.tsx`) currently
simulates a submission and shows a success message — there is no backend
wired up. To connect it to a real service:

**Option A — Formspree** (fastest):
1. Create a form at [formspree.io](https://formspree.io) and copy its
   endpoint URL.
2. In `handleSubmit`, replace the simulated delay with:
   ```ts
   const formData = new FormData(e.currentTarget);
   const res = await fetch("https://formspree.io/f/your-form-id", {
     method: "POST",
     body: formData,
     headers: { Accept: "application/json" },
   });
   if (!res.ok) throw new Error("Submission failed");
   ```

**Option B — Resend** (more control):
1. Create a Next.js API route at `src/app/api/contact/route.ts` that
   calls the Resend API with your API key (stored as a server-side
   environment variable, **not** a `NEXT_PUBLIC_` one).
2. POST the form data to `/api/contact` from `handleSubmit` instead.

## 10. Deploying to Vercel

1. Push this project to a GitHub repository (see below).
2. Go to [vercel.com/new](https://vercel.com/new) and import the repo.
3. Add the environment variables from section 4 in the Vercel project
   settings (Settings → Environment Variables).
4. Deploy. Vercel will detect Next.js automatically — no extra
   configuration is required.

### Connecting a custom domain

1. In your Vercel project, go to Settings → Domains.
2. Add your domain (e.g. `vaigasweets.com`).
3. Update your domain's DNS records as instructed by Vercel (usually an
   `A` record or `CNAME` pointing at Vercel).
4. Once verified, also update `url` in `src/data/site.ts` to match your
   real domain — this is used for SEO metadata, the sitemap, and
   structured data.

## 12. Project structure

```
src/
  app/                 Routes (App Router): home, about, products, gallery, contact, privacy-policy
  components/
    layout/            Navbar, Footer, WhatsApp floating button
    home/               Homepage sections
    products/           Product card + category filter
    gallery/             Masonry grid + lightbox
    contact/             Contact form
    ui/                  Shared building blocks (Button, SectionHeading, LeafDivider, Reveal)
  data/                Editable content: site.ts, products.ts, categories.ts, testimonials.ts, gallery.ts
  lib/                 whatsapp.ts — central link builders
public/
  images/              Placeholder artwork, organized by section
scripts/
  gen-placeholders.mjs Regenerates placeholder SVG artwork (optional, for reference)
```

## 13. Notes on content

- Testimonials in `src/data/testimonials.ts` are placeholders and are
  **not** presented as verified or Google reviews — replace with real
  customer feedback once collected.
- Prices are intentionally shown as "Contact us" rather than invented
  figures — update `price` per product in `src/data/products.ts` once
  real pricing is finalized.
- The Google Maps embed and business address in `src/data/site.ts` are
  placeholders — replace with your real address and a map embed URL
  from Google Maps → Share → Embed a map.
